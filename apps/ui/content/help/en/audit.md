The audit log records every admin action: who, what, when and on what. Open it under **Admin → Audit log**.

## What is recorded

- Creating, renaming, disabling and enabling actors; password resets.
- Issuing and revoking tokens.
- Giving and removing roles; creating and editing roles and policies.
- Creating, editing and archiving projects; changing read retention.
- Hiding and showing content; changing search settings, recomputing vectors; completing setup.

## How to find an event

1. Filter by who did it, project, kind of action and date range (in UTC).
2. Events are grouped by day, newest first.
3. Click a row to see every detail.

## Share and export

- Each event has a **Link to this event** to send to someone.
- **Export CSV** downloads every event that matches the current filters.

> [!NOTE]
> A project manager only sees role changes and hidden content in their own projects. Each actor's page also has an **Activity** tab for that actor alone.
