Most of the work can be done from the keyboard. Press `kbd:?` on a project page to see this list again.

## Command palette

Press `kbd:⌘K` (Windows, Linux: `kbd:Ctrl K`) anywhere:

- Jump to a project.
- In a project: **Add a claim**, **Ask a question**, or type two characters or more to find a contribution.
- Admins: jump to admin pages and actors.

Use `kbd:↑` `kbd:↓` to pick, `kbd:Enter` to open, `kbd:Esc` to close.

## On a project page

- `kbd:j` / `kbd:k`: next / previous row.
- `kbd:Enter`: open the selected row.
- `kbd:c`: add a claim.
- `kbd:/`: go to the search box.
- `kbd:?`: show the shortcuts.

## On a claim's page

- `kbd:[` / `kbd:]`: previous / next contribution in the list you came from.
- **Back to list** takes you back to that list, filters and all.

> [!NOTE]
> Shortcuts do nothing while you type in a field or while a dialog is open.
